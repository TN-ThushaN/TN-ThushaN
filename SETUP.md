## If the action fails

- Ensure the repository is the special profile repository (repository name exactly matches your username).
- Check **Settings → Actions → General** to ensure GitHub Actions are allowed.
- Confirm workflow run logs. If a workflow cannot push a change, check organization/repository restrictions and workflow permissions; these files explicitly request `contents: write`.
- The `output` branch is generated by the snake workflow. Don't manually create an empty SVG.
- If images still fail to appear immediately, wait briefly for GitHub's raw-content caches and refresh the page.
