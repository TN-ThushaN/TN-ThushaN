# 🎓 Academic Projects & Research

These projects represent my academic work, practical learning and exploration of different computing disciplines.

### 🌧️ 8. Kelaniya Flood Impact on Road Network Analysis

**Technologies:** Python | Graph Theory | OpenStreetMap | NetworkX | GeoJSON

- Constructed a real-world road network using OpenStreetMap data.
- Analyzed 10,770 road-network nodes and 20,727 directed edges.
- Investigated road segments intersecting flood-affected areas.
- Analyzed network connectivity before and after flood exposure.
- Evaluated shortest paths and potential alternative routes.
- Applied graph theory to study road accessibility and network resilience.

**Project type:** DS5106 Graph Theory Academic Project.

### 🚲 9. Bike Sharing Demand Forecasting

**Technologies:** Python | Pandas | Machine Learning | Regression

- Explored historical bike-sharing demand patterns.
- Investigated weather, seasonality and time-related variables.
- Applied data preprocessing and feature engineering.
- Explored supervised regression models.
- Studied MAE, RMSE and R² for model evaluation.

**Project type:** Data Science Capstone Project.
